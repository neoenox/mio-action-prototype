## 見つけた不自然さ

**先に結論**: 4 つのうち 2 つは**コード上で意図的な選択**だった（理由も書かれている）。
「不自然に見える」と「直すべき」は別なので、分けておく。

### 1. 歩行中、腕が振れない — 意図的（判断が要る）

- 脚は大きくストライドするのに、**両手を腹の前で組んだまま**で腕が動かない。
  3 行（前進・横歩き・後退り）× 7 コマすべてで同じ。
- コード: `CharacterAnimator.Pose.cs:338`「構えを崩さない。歩いても拳は顔の前に残し…」
  `ArmSwing` は効いているが、**両手を組んでいるため振りが画に出ない**。
- つまり「実装漏れ」ではなく「構えを優先した結果、振りが読めなくなっている」。
  直すなら歩きのときだけ拳を腰の横へ下ろす。設計判断が要る。

### 2. 攻撃の拳が服と同化して読めない — 本物（見せ方の問題）

- 3 段コンボの振り抜きで、**白い拳が白い服と同じ色**になり、どこまで腕が伸びたか分からない。
- 肩の踏み込みも画から伝わりにくい（体の回転が小さい）。
- ポーズではなく**色・光・輪郭**の問題。拳を濃くする、リムライトを当てる、など。

### 3. ダウンで膝が伸びたまま — 意図的

- `down_sheet.png` の接地後、両脚がまっすぐ伸びている。
- コード: `CharacterAnimator.PoseDown.cs:75`「膝から落ちる。**落ちきる前に脚を伸ばして、
  うつ伏せで真っ直ぐにする**」。畳んだままだと脚が不自然に折れるための処置。
- **計測（`motion_audit.py --sheet down_sheet.png --rows 5 --cols 3`）**:
  行 = 時刻（t=0.5 / 0.7 / 0.9 / 1.1 / 2.0）、列 = 視点。時間方向の差分は
  `16.7 → 2.6 → 0.09 → 0.28`（1 列目）。**t=0.9 以降は平均の約 2% しか動いていない**。
- 落下は `_downFallSeconds = 0.95` で終わるので、静止自体は仕様。
  ただし**1 秒以上まったく動かない**ので、画としては止まって見える。
  呼吸は 3mm（`PoseDown.cs:114`）で、この解像度では差が出ない。
- 直すなら呼吸を 1〜2cm に上げる、頭や指を少し動かす。**意図（静かに倒れている）は保てる**。

### 4. 押さえつけ → 腹パン演出のカメラが飛ぶ — 本物（構造）

- 隣接フレームの差分で **平均の 6.3 倍**（`#112→#113`）。1 フレームで別角度の寄りに変わる。
- 原因は 2 系統のカメラ（cinematic と Push/HoldFocus）を同一シーンで受け渡していること。
  `ThirdPersonCamera.ApplyCinematicShot` はショット開始時に `follow = 1` で即移動する。
- 補間を足す案は**試して取り消した**。既存の構図テスト 4 件が落ち、
  壁の可視率が 84% → 59% に悪化した（カメラの「寄る速さ」はテストが意図として持っている）。
- 次は「受け渡しを跨がない」か「カットとして見せる（暗転・タメ）」のどちらか。

### 5. 壁 3 人がかりの顔の遮蔽（改善済み・残りあり）

- 拘束・膝 84% / 猶予 92% / 二人がかり 96% / 3 人がかり 85%（`FaceVisibility.RequiredRatio` で下限を固定）。
- 3 人がかりで残るのは拘束役の体（`byRole=拘束役:204`）と、向きで読めないコマ。

### 6. 敵の攻撃 — 明確な不自然さは見つからず

- `enemy_attacks.png`（4 種 × 予備動作/振り抜き/戻り）を確認。
- 低解像度だと**足が浮いて見える**が、拡大すると**接地していた**（靴底と影が接触）。
  小さく写るコマで「浮いている」と判断しないこと。

### 7. 立ち上がり — このキャプチャでは判断できない

- `getup_sheet.png` は t=0.02 / 0.18 / 0.34 / 0.48 / 0.62 / 0.78（duration 0.80）。
- t=0.34 のコマは**宙に浮いて見える**が、**このシートには床が写っていない**（背景のみ）ので、
  接地しているかどうかを判断できない。撮り直して床と影を入れる必要がある。
- 同様に、床の無いキャプチャで「接地が不自然」と結論しないこと。

## 次にやるなら

**直すべきは 2 と 4**。1 と 3 は設計判断なので、触る前に方針を決める。

1. **攻撃の拳が見えない**（2）— 色と光だけ。ポーズに触らないので安全。
2. **カメラの受け渡し**（4）— 設計寄り。方針を決めてから。
3. 歩きの腕（1）・ダウンの経過（3）— どちらも「意図を変える」話なので、決めてから。
