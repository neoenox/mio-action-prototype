## 見つけた不自然さ

### 1. 歩行中、腕が振れない（判断が要る）

- 脚は大きくストライドするのに、**両手を腹の前で組んだまま**で腕が動かない。
  3 行（前進・横歩き・後退り）× 7 コマすべてで同じ。
- コード上は意図的（`CharacterAnimator.Pose.cs:338`「構えを崩さない。歩いても拳は顔の前に残し…」）。
  `ArmSwing` は効いているが、**両手を組んでいるため振りが画に出ない**。
- 直すなら「歩きのときだけ手を組まない（拳を腰の横へ下ろす）」。
  ただし設計意図（構えを崩さない）と衝突するので、どちらを取るか判断が要る。

### 2. 攻撃の拳が服と同化して読めない

- 3 段コンボの振り抜きで、**白い拳が白い服と同じ色**になり、どこまで腕が伸びたか分からない。
- 肩の踏み込みも画から伝わりにくい（体の回転が小さい）。
- 直すなら拳の色を変える・手袋を濃くする・リムライトを当てる。ポーズではなく見せ方の問題。

### 3. ダウンで膝が伸びたまま（人形っぽい）

- `down_sheet.png` の接地後、**両脚がまっすぐ伸びている**。崩れ落ちる動きなら膝が抜ける。
- 接地してからの姿勢が 4 コマともほぼ同じで、静止画のように見える（経過が伝わらない）。
- 直すなら接地後に膝を曲げ、上体を少しずらす。

### 4. 押さえつけ → 腹パン演出のカメラが飛ぶ

- 隣接フレームの差分で **平均の 6.3 倍**（`#112→#113`）。1 フレームで別角度の寄りに変わる。
- 原因は 2 系統のカメラ（cinematic と Push/HoldFocus）を同一シーンで受け渡していること。
  `ThirdPersonCamera.ApplyCinematicShot` はショット開始時に `follow = 1` で即移動する。
- 補間を足す案は**試して取り消した**。既存の構図テスト 4 件が落ち、
  壁の可視率が 84% → 59% に悪化した（カメラの「寄る速さ」はテストが意図として持っている）。
- 次は「受け渡しを跨がない」か「カットとして見せる（暗転・タメ）」のどちらか。

### 5. 壁 3 人がかりの顔の遮蔽（改善済み・残りあり）

- 拘束・膝 84% / 猶予 92% / 二人がかり 96% / 3 人がかり 85%（`FaceVisibility.RequiredRatio` で下限を固定）。
- 3 人がかりで残るのは拘束役の体（`byRole=拘束役:204`）と、向きで読めないコマ。

## 次にやるなら

優先度は「読めない」問題から。

1. **攻撃の拳が見えない**（2）— 色と光だけで直る。ポーズに触らないので安全。
2. **ダウンの膝**（3）— 接地後の姿勢だけ。`PoseDown` の 1 箇所。
3. **歩きの腕**（1）— 設計判断が要る。決めてから。
4. **カメラの受け渡し**（4）— 設計寄り。方針を決めてから。
