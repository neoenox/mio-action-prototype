# プレイヤーのダウン（ひるみ値 → 放物線で吹き飛ぶ）— 設計メモ

日付: 2026-11-06
状態: 実装済み（`feat/player-down`）。EditMode 27 / PlayMode 64 通過。

## 決めたこと

### 1. ダウンする条件は「ひるみ値（ダウンゲージ）が 100」

既存の 2 つのリソースと役割を分ける。

| リソース | 0 になったら |
|---|---|
| スタミナ | **ガードブレイク = ダウン**（既存） |
| 体勢（ポスチャー） | 大怯み 0.8 秒（既存） |
| **ひるみ（新規）** | **ダウン** |

ひるみは「殴られ続けたら倒れる」を担当する。ポスチャーは「重い一撃で崩される」、
ひるみは「数で押されて蓄積する」。3 つ目を足すことで、ガードしていなくても倒れる。

### 2. 攻撃ごとのひるみ値

| 攻撃 | ひるみ | 何発でダウン |
|---|---|---|
| 軽（8dmg） | 12 | 9 発 |
| 重（18dmg） | 26 | 4 発 |
| 崩し（14dmg・脚） | 34 | 3 発 |
| 掴み | 6 | ほぼ溜まらない |
| 押さえつけの膝（4dmg） | 8 | 5 発で 40（単体では倒れない） |
| タッグ腹パン | 10 | 同上 |
| ガード中の被弾 | **×0.35** | ガードしても完全には防げない |

`AttackData.flinch` が 0 のままなら `AttackKind` から既定値を出す
（押さえつけの膝のように、その場で `new AttackData` する経路を書き漏らさないため）。

### 3. 減衰

- 最後の被弾から **1.5 秒**は減らない
- そこから **10/秒** で抜ける
- つまり「殴られ続けている間は溜まり続け、手が止まれば戻る」

### 4. 無限ダウンの防止（追撃ありの前提）

他の敵はダウン中も殴る（ユーザー判断）。そのままだと
「倒れる → 起き上がり中に殴られる → また倒れる」で永久に立てなくなるので 2 つ入れた。

1. **ダウン中はひるみを加算しない**（ダメージは入る）
2. **起き上がり完了後 1.0 秒はダウンしない**

ダウン中の被弾は HP だけが減る。起き上がり（0.8 秒）は無防備なので、そこが正念場になる。

## 倒れ方: 後ろへ放物線

```
被弾 → ひるみ 100
  → 水平 1.6m / 浮き 0.55m で後ろへ飛ぶ（滞空 0.45 秒）
  → 着地 → 仰向け（既存の Down ポーズ）→ 起き上がり 0.8 秒
```

- 浮きは初速で与える（`v = sqrt(2gh)`）。あとは `PlayerMotor` の重力が放物線を作る
- 倒れきる時刻を着地に合わせる（`DownFallSeconds` 0.95 → 0.52 秒）。
  そのままだと「空中なのに、その場で崩れる速さで倒れる」ように見える
- 空中では脚を前へ流す（`footL/R` を +Z へ）。着地で外す

### カメラ

`BeltFollowSharpness` は 5 で、1.6m を 0.45 秒で飛ぶ彼女に負ける。
倒れている間だけ **16** に上げた（`DownFollowSharpness`）。
上げないと、倒れた姿が画面の左端で切れる（実測して直した）。

## 検証

```
MioPrototype.exe -nofeint -statlog -downburst=<dir>\d.png
```

- 軽 9 発（0.30 秒間隔）でダウン → `[Launch] 1.60m h=0.55 air=0.45s` → 着地
- 0.05 秒×40 枚で、飛ぶ → 着地 → 仰向け → 起き上がりまで確認
- `-downhits=heavy` で 4 発、`-downhits=break` で 3 発

## 未対応・次の候補

- 倒れる向きは 1 種類（後ろ）。腹を抱えて**前へ崩れる**バリエーションは未着手
- ダウン中の追撃を「踏みつけ」など専用モーションにはしていない（通常のパンチが当たる）
- ひるみゲージは HUD に出していない（見えないと理不尽に見える可能性。要検討）
- 吹き飛び中に敵を通り抜ける（ベルト 1 ラインなので衝突判定が無い）
