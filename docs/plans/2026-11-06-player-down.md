# プレイヤーのダウン（ひるみ値 → 放物線で吹き飛ぶ）— 設計メモ

日付: 2026-11-06
状態: 実装済み（`feat/player-down`）。EditMode 27 / PlayMode 64 通過。

## 決めたこと

### 1. ダウンする条件は「ひるみ値（ダウンゲージ）が 100」

既存の 2 つのリソースと役割を分ける。

| リソース | 0 になったら |
|---|---|
| スタミナ | **ガードブレイク = ダウン**（既存） |
| 体勢（ポスチャー） | 大怯み 0.8 秒（既存） |
| **ひるみ（新規）** | **ダウン** |

ひるみは「殴られ続けたら倒れる」を担当する。ポスチャーは「重い一撃で崩される」、
ひるみは「数で押されて蓄積する」。3 つ目を足すことで、ガードしていなくても倒れる。

### 2. 攻撃ごとのひるみ値

| 攻撃 | ひるみ | 何発でダウン |
|---|---|---|
| 軽（8dmg） | 12 | 9 発 |
| 重（18dmg） | 26 | 4 発 |
| 崩し（14dmg・脚） | 34 | 3 発 |
| 掴み | 6 | ほぼ溜まらない |
| 押さえつけの膝（4dmg） | 8 | 5 発で 40（単体では倒れない） |
| タッグ腹パン | 10 | 同上 |
| ガード中の被弾 | **×0.35** | ガードしても完全には防げない |

`AttackData.flinch` が 0 のままなら `AttackKind` から既定値を出す
（押さえつけの膝のように、その場で `new AttackData` する経路を書き漏らさないため）。

### 3. 減衰

- 最後の被弾から **1.5 秒**は減らない
- そこから **10/秒** で抜ける
- つまり「殴られ続けている間は溜まり続け、手が止まれば戻る」

### 4. 無限ダウンの防止（追撃ありの前提）

他の敵はダウン中も殴る（ユーザー判断）。そのままだと
「倒れる → 起き上がり中に殴られる → また倒れる」で永久に立てなくなるので 2 つ入れた。

1. **ダウン中はひるみを加算しない**（ダメージは入る）
2. **起き上がり完了後 1.0 秒はダウンしない**

ダウン中の被弾は HP だけが減る。起き上がり（0.8 秒）は無防備なので、そこが正念場になる。

## 倒れ方 2: 前へ崩れる（腹を殴られた → うつ伏せ）

腹を殴られてひるみが上限に達したときは、**飛ばさずにその場で膝が抜けて前へ倒れる**。

```
腹ヒット → ひるみ 100 → 膝が抜けて腰が落ちる
  → 体が前へ 92° 倒れる（0.78 秒）→ うつ伏せ
  → 1.2 秒 → 起き上がり 0.8 秒（手で床を押して膝立ち → 立つ）
```

- 判定は `PlayerStats.LastHitZone == PunchZone.Body`。投げは `LastHitZone` を消してから呼ぶので後ろ倒れになる
- `hipsOffset.z` を +0.78m 前へ出す。仰向けのとき腰が 0.87m 後ろへ回るのと裏返しで、
  出さないと脚が畳まれる

### うつ伏せからの起き上がり（3 段）

仰向けの「横に転がって座る」曲線は使えない（腹這いのまま背中側へ転がる）。専用に作った。

| 段 | u | 動き |
|---|---|---|
| 1 | 0.00–0.34 | 両手を頭の横について上体を押し上げる（体の角度 92° → 54°） |
| 2 | 0.30–0.66 | 右の片膝を前へ出して膝立ち（角度 28°、腰を 0.46m まで上げる） |
| 3 | 0.62–1.00 | 立ち上がって構えへ（角度 0°、腕は構えへ、腰は立ち位置へ） |

- 脚は `LayBody` の後に解き直している（うつ伏せと同じ理由）
- **腕も `LayBody` の後に世界の向きで置き直す**。体を回す前に「上」で組むと、
  体が起きるにつれて腕が上を向き、**バンザイで起き上がる**（実測して直した）。
  手は地面（-Y）、肘は外（±側方）へ向け、起き上がり u=0.55〜0.92 で構えの腕へ戻す

### うつ伏せが最初は破綻した理由と直し方（重要）

最初の実装では**脚が宙を向いて**破綻した。原因は姿勢の適用順:

```
1. 脚の IK（SolveLeg）  ← 床に足を置く
2. LayBody（体を 92° 回す） ← 解いた脚ごと回すので、足が宙へ飛ぶ
```

`LayBody` が脚の IK より後に来るため、脚を解いた後に体を回すと脚が付いてくる。
**うつ伏せのときだけ、`LayBody` の後にもう一度 `SolveLeg` する**ことで解決した
（回した後の骨格から足先へ引き直すので、床に沿った脚になる）。

```csharp
if (Mathf.Abs(layAngle) > 0.01f)
    Rig.LayBody(layAngle, laySide);

// うつ伏せだけ、回した後に脚を解き直す
if (_downForward && (_state == State.Down || _state == State.GetUp)
    && needLegSolve && layAngle > 1f)
{
    Rig.SolveLeg(true, transform.TransformPoint(footL), pole);
    Rig.SolveLeg(false, transform.TransformPoint(footR), pole);
}
```

### 腹パンからのうつ伏せ（掴まれたまま限界）

掴まれている最中もひるみは溜まる（膝 10×腹ヒット倍率2 / 腹パン 12×2）。ただし掴まれたまま倒すと姿勢が壊れるので、
**上限に達したら「待ち」にして、掴みが解けた瞬間に倒す**（`PlayerStats._pendingDown`）。

- 逃げられた（もがき成功）→ その場でうつ伏せ
- 押さえつけの時間切れ → **投げずに手を離す**（`PlayerGrapple.Fail`）。
  投げると後ろへ飛んでしまい「腹を殴られ続けて立てなくなった」に見えない
- 後ろ拘束は時間切れが無いので、**もがきで逃げたときにだけ**うつ伏せになる
  （腹パンの途中で勝手に離すと 5 発のコンボが途切れる）
- 投げ（時間切れ）で先に倒れた場合は待ちを破棄する

## 倒れ方（後ろ）

```
被弾 → ひるみ 100
  → 0.35m 下がりながら 0.16m 浮く（滞空 0.24 秒）
  → 0.32 秒で倒れきる（着地とほぼ同時）→ 仰向け → 起き上がり 0.8 秒
```

試作の履歴（数値の根拠）:

| 版 | 動き | 結果 |
|---|---|---|
| 初版 | 1.6m / 0.55m / 0.45 秒 | **吹き飛びすぎ**（ユーザー評）。カメラが負けて画面の端で切れた |
| 2版 | 0.78m / 0.16m | 距離は収まったが「板が倒れる」ように見えた |
| 3版 | root 0.35m に減らし、姿勢側で倒す | スライド感が消えた |

「ゲームっぽくない」の正体は **板倒し**だったので、次の 5 つを入れた。

1. **足を浮かせる**: 支点を足元に固定したまま、`footL/R` を山なりに浮かせる。
   かかとを支点に回すと「後ろへ倒した板」になる
2. **速く倒す**: 0.52 秒 → 0.32 秒。ゆっくり傾くと「倒されている途中を眺める」画になる
3. **二次動作（腕）**: 被弾で腕が前へ振られ、倒れながら横へ開く
4. **背中の反り**: 倒れている途中だけ上体を 15° 反らせ、頭を 13° 遅らせる
5. **寝きった姿勢**: 片膝を立て、右腕を腹の上へ、体を 6° 横へ流す。
   脚を伸ばしたまま真っ直ぐ寝ると「床に置いた人形」に見える

### カメラ

`BeltFollowSharpness` は 5 で、倒れる彼女に負ける。倒れている間だけ **16** に上げた
（`DownFollowSharpness`）。初版の 1.6m では、これが無いと倒れた姿が画面の端で切れた。

## 検証

```
MioPrototype.exe -nofeint -statlog -downburst=<dir>\d.png
MioPrototype.exe -nofeint -downburst=<dir>\d.png -downlaunch=1.5   # 飛距離の撮り比べ
```

- 軽 9 発（0.30 秒間隔）でダウン → `[Launch] 0.35m h=0.16 air=0.24s` → 着地
- 0.05 秒×40 枚で、倒れる → 着地 → 片膝を立てて寝る → 起き上がりまで確認
- `-downhits=heavy` で 4 発、`-downhits=break` で 3 発
- `-downlaunch=<倍率>` で飛距離を再ビルドなしに撮り比べられる（既定 1.0）

## 未対応・次の候補

- ダウン中の追撃を「踏みつけ」など専用モーションにはしていない（通常のパンチが当たる）
- ひるみゲージは HUD に出していない（見えないと理不尽に見える可能性。要検討）
- 倒れた彼女と敵の脚が重なる（ベルト 1 ラインで衝突判定が無い）
- 起き上がり（既存の 0.8 秒）は倒れ方ほど作り込んでいない
