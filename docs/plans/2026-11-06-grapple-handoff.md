# 拘束の引き渡し（たらい回し）— 設計メモ

日付: 2026-11-06
状態: 土台のみ実装（`HandOff` / `TakeOverHold` / `GrappleHandOff`）。突き飛ばし演出は未実装。

## 狙い

3 体で戦っているとき、拘束している敵が彼女を**別の敵へ突き飛ばして渡す**。
抜けても次の敵に捕まるので、「数で押される」圧力が出る。

## 流れ（提案どおり）

```
1人目が拘束（後ろ / 押さえつけ）
  └ タッグ腹パンのコンボが終わる
      ├ 抽選: 突き飛ばし（正面向き）
      │    └ 2人目が正面拘束（Pin）→ 膝蹴り
      └ 抽選: 突き飛ばし（背面向き）
           └ 2人目が羽交い締め（Back）→ 腹パン条件を満たせばタッグ腹パン
```

- **正面向き**: そのまま `GrappleKind.Pin`（膝蹴り派生あり）
- **背面向き**: `GrappleKind.Back`。背を向けるので**回転モーションを挟む**
- どちらも「腹パン条件を満たしたら腹パン実施」＝既存の `HeldBellyPunchDirector` の判定をそのまま使う

## 実装の分担（案）

| 部分 | 内容 | 状態 |
|---|---|---|
| `PlayerGrapple.HandOff` | 掴まれたまま相手を差し替え、位置を寄せ直す。もがき進捗と制限時間をリセット | **実装済み** |
| `EnemyBrain.TakeOverHold` | 新しい掴み手が `Recover` + `IsHolding` でその場に留まる | **実装済み** |
| `GrappleHandOff` | 2.6 秒ごとに引き渡しを抽選。押さえつけ・タッグ腹パン中は除外 | **実装済み** |
| 突き飛ばし | 1人目が彼女を 0.8〜1.0m 押し出す（0.3 秒）。`PlayerMotor.Knockback` 相当 | 未実装 |
| 回転 | 背面向きのとき、押し出しながら 180° 回す（0.25 秒） | 未実装 |
| 受け渡しの見た目 | 1人目は押したあと半歩引く／2人目は受け止める構え | 未実装 |

## 決めておくこと

- **抽選比**: 正面 : 背面 = 50 : 50（腹パンを見せたいなら背面寄り）
- **突き飛ばしの距離**: 0.9m（2人目が 1.0m 以内にいること）
- **突き飛ばし中の無防備**: 押されている 0.3 秒は入力を受け付ける（もがきは無効）
- **押さえつけの引き渡し**: 4.2 秒の短い技なので**対象外**（今の実装どおり）
- **タッグ腹パン中の引き渡し**: 演出が壊れるので**しない**（今の実装どおり）

## 現状の制約

- いまの引き渡しは**瞬間移動**（`SnapToCaptor`）。上の「突き飛ばし」を入れると自然になる
- 引き渡しのテスト（`拘束は別の敵へ引き渡せる`）は追加済みだが**未実行**
