# 拘束の引き渡し（たらい回し）— 設計メモ

日付: 2026-11-06
状態: 実装済み（`feat/grapple-handoff`）。受け手の「構え」だけ未着手。

## 狙い

3 体で戦っているとき、拘束している敵が彼女を**別の敵へ突き飛ばして渡す**。
抜けても次の敵に捕まるので、「数で押される」圧力が出る。

## 流れ（提案どおり）

```
1人目が拘束（後ろ / 押さえつけ）
  └ タッグ腹パンのコンボが終わる
      ├ 抽選: 突き飛ばし（正面向き）
      │    └ 2人目が正面拘束（Pin）→ 膝蹴り
      └ 抽選: 突き飛ばし（背面向き）
           └ 2人目が羽交い締め（Back）→ 腹パン条件を満たせばタッグ腹パン
```

- **正面向き**: そのまま `GrappleKind.Pin`（膝蹴り派生あり）
- **背面向き**: `GrappleKind.Back`。背を向けるので**回転モーションを挟む**
- どちらも「腹パン条件を満たしたら腹パン実施」＝既存の `HeldBellyPunchDirector` の判定をそのまま使う

## 実装の分担（案）

| 部分 | 内容 | 状態 |
|---|---|---|
| `PlayerGrapple.HandOff` | 掴まれたまま相手を差し替え、位置を寄せ直す。もがき進捗と制限時間をリセット | **実装済み** |
| `EnemyBrain.TakeOverHold` | 新しい掴み手が `Recover` + `IsHolding` でその場に留まる | **実装済み** |
| `GrappleHandOff` | タッグ腹パン 5 発を食らい切ったときに、次の敵への引き渡しを 1 度だけ抽選（`TryChain`、既定 70%）。腹ダメージが上限なら抽選せずにうつ伏せダウン、外れたら元の拘束が続く | **実装済み** |
| 突き飛ばし | 1人目が腕を突き出し、彼女を掴み位置まで一続きに押し出す（0.18〜0.65 秒）。行き過ぎて戻さない | **実装済み** |
| 回転 | 前向き／後ろ向きを抽選し、押し出されながら 0.25 秒で向きを変える（`Slerp`） | **実装済み** |
| 2人のロック | 渡す側は `LockForHandOff(0.9)`、受け手は `TakeOverHold` でその場に固定 | **実装済み** |
| 1人目の腕 | `EnemyBrain.PushAway()` → 0.22 秒だけ両腕を突き出す | **実装済み** |
| 彼女の姿勢 | `PlayerGrapple.PushPulse` → 上体 +20°、腕を後ろへ 45°、顔は起こす（0.35 秒） | **実装済み** |
| 受け手の構え | 2人目が受け止める構え（腕を軽く開く） | **実装済み**（`IsCatching`） |

## 決めておくこと

- **抽選のタイミング**: タッグ腹パン 5 発の完了時（時間経過では渡さない。以前は 2.6 秒ごとだったが、腹パンも膝蹴りも出ないうちに渡って「たらい回し」になった）
- **腹ダメージが上限のとき**: 引き渡さずに解放し、うつ伏せにダウンする（1 コンボ = 80 なので、腹パンだけでは上限に届かない。膝蹴りか 2 コンボ目で届く）
- **抽選比**: 正面 : 背面 = 50 : 50（腹パンを見せたいなら背面寄り）
- **突き飛ばしの距離**: 固定 0.9m ではなく、受け手から掴み位置（Back 0.34m / Pin 0.60m）まで。受け手は 2.5m 以内から選ぶ
- **突き飛ばし中の無防備**: 押されている 0.3 秒は入力を受け付ける（もがきは無効）
- **押さえつけの引き渡し**: 4.2 秒の短い技なので**対象外**（今の実装どおり）
- **タッグ腹パン中の引き渡し**: 演出が壊れるので**しない**（今の実装どおり）

## 現状の制約

- 押し出しは `Knockback`（滑る）なので、**足は自分で運んでいない**。気になるなら足の運搬を足す
- 押す側は押したあと**その場に残る**（半歩引く動きは未実装）
- 受け手は「腕を開いて半歩かがむ」構えを 0.9 秒だけ取る（彼女が届くまで＋掴んだ直後）。Pin では `PinHoldPose` が腕を掴み位置へ引き直すので、構えはほぼ見えない（背面でよく見える）
- 見え方の実測: 押す側が棒立ちだと「2人目が掴みに来た」に見える。押す側の腕を出してからは突き飛ばしに見える（ユーザー判断でこのまま採用）
- 引き渡しのテスト（`拘束は別の敵へ引き渡せる`）は追加済み・PlayMode 60/60 で通過

## 姿勢を足すときの注意

`ApplyPose()` の前に足すと毎フレーム上書きされて消える（2 回空振りした）。
必ず `ApplyPose()` の**後**（`LateUpdate` の末尾）に書く。詳細は `docs/GRAPPLE_NOTES.md` の 7.1。
