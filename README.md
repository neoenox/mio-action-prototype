# MIO PROTOTYPE — 操作と遊び方

女性主人公のベルトアクション（横スクロール格闘）の試作です。
性的な表現はありません。暴力は「痛み・抵抗・踏ん張り」までに限定しています。

---

## 起動

`MioPrototype\Build\MioPrototype.exe` をダブルクリックしてください。

1. すぐ始まります（タイトルは出ません。操作の説明は画面の右下にあります）
2. そのまま遊べます（インストール不要）

### 常に最新のコードで起動する

`Build/` は Unity が自動で作り直すので、exe をそのまま起動すれば最新です。

- Unity を開いている間: スクリプトを保存してコンパイルが終わってから 15 秒ほどで、
  `Build/` が自動更新されます（メニュー `Ryona > Auto Build Player (On Compile)` で切替）
- Unity を閉じているとき: `MioPrototype\tools\BuildAndPlay.cmd` をダブルクリック。
  差分があるときだけバッチビルドしてから exe を起動します
- 手動: エディタのメニュー `Ryona > Build Windows Player`

## 操作

| 操作 | キーボード | コントローラ |
|---|---|---|
| 移動 | A / D / 左右矢印キー | 左スティックの左右 |
| 弱攻撃 | J | A（下） |
| 強攻撃 | K | X（左） |
| 崩し攻撃 | L | Y（上） |
| カメラ | マウスホイールでズーム | 固定 |
| 振りほどき | J / K / L / Space を連打 | A / X / Y を連打 |
| 倒れた時の復帰 | R | スタート |
| ゴッドモード | G（切替） | なし |
| 一時停止 | Esc | スタート |

一時停止メニューでは **R ではじめから**、**← → で音量**、**↑ ↓ でカメラ感度**、**Q で終了**。

マウスはゲームにロックされません（カーソルは表示されたまま）。ホイールのズームだけを使います。

## 遊びの流れ

- キャラクターは横一列で戦います。奥や手前への移動はありません。
- 敵が **3 体ずつ**湧いてきます。全滅させると次の一団が来ます
- **10 波（30 体）**片付けると **STAGE CLEAR**
- 倒した敵は起き上がって再び向かってきます（倒しっぱなしにはできません）

## うまく戦うコツ

- **弱 → 弱 → 強** の 3 段コンボ（0.45 秒以内につなぐ）
- 敵は素手で攻撃します。強い攻撃には**予備動作の音**が出ます
- 予備動作のあとに**振らずに引く**ことがあります（フェイント）。音と間合いで見ます
- **背後に回られると掴まれます（羽交い締め）。正面からは掴まれません**。後ろ拘束は**時間切れで解けない**ので、連打で振りほどくか、タッグ腹パンを 5 発食らうかになります。振りほどくと相手がよろけて隙ができます。5 発食らっても拘束は解けず、**腹ダメージが上限（100）に達していればうつ伏せにダウン**、未満なら **70% で別の敵に引き渡され**、外れると元の敵が拘束を続けます
- **正面からも掴まれます**。肩を押さえて膝を入れる**押さえつけ**と、胴を抱えて締め付ける**ベアハッグ**があります。どちらも最初の **2.7 秒**は連打で攻撃前に脱出できます。その後も、押さえつけは掴まれてから **5.8 秒**、ベアハッグは **6.3 秒**まで抵抗できます
- **壁拘束**は、掴み → 壁のせり上がり → 壁への叩きつけ（SEと揺れ） → 壁に沿ってずり落ちる → 両腕を掴んで引き起こす → 両手首の頭上固定 → 膝蹴りの順に続きます。壁は開始地点を含む4か所で、掴まれてから現れます。壁が出る間と固定後は連打で脱出できます。最後の膝蹴りのあとは、壁からレーンへ**投げ捨てられてダウン**します（仰向け／うつ伏せはランダム）。
- **壁拘束に別の敵が加わると「2人がかり（Y字）」**になります。膝蹴りの代わりに、2 体が左右から片腕ずつを掴んで彼女を Y 字に固定し、空いた手で腹パンを **3 発ずつ交互（計 6 発）**。殴られるたびに壁に固定されたまま上体が折れ、膝が抜けて、次の一発までに立て直します。脱出の連打は通常の 1.5 倍（18 回）必要です。6 発のあとは 1 体のときと同じく**投げ捨てられてダウン**します。
- 羽交い締め中に**正面の別の敵の投げ**が決まると、タッグ腹パンに派生します。投げ自体はダメージも怯みもなく、彼女は腹を差し出す体勢へ移ってそのまま連撃に入ります（「く」の字に折れるのはパンチが当たったときだけ）。投げのあとに腹パンと顔面パンチが計 **5 発**続きます。通常パンチも一発ずつ命中し、ダメージが入ります。連撃中も連打で抜けられます
- 画面手前に入った敵は**薄く表示**されます（彼女が隠れないように）
- 脚を殴られると移動が遅くなり、腕を殴られると与ダメージが落ちます（部位ダメージ）

## 動作環境

- Windows 10 / 11（64bit）
- キーボード、または Xbox 系コントローラ
- ビルドサイズ 約 109MB

## 既知の割り切り（試作のため）

- 敵 3 体は同じ見た目です（白いアンドロイド風のプリミティブ。色違いなどの個体差は未実装。VRM の差し替えは 1 体分のみ検証済み）
- 敵の見た目はプリミティブ（球・カプセル）で、装甲の彫刻ディテール・顔の造形・布や髪の質感は出ません
- VRM の敵は表示が 1 フレーム遅れます
- 遮蔽は敵を「消す」方式です（VRM のシェーダ制約）
- ステージの端（x≒38.6）まで行くと、それ以上は進めません

## 検証用の起動引数（開発用）

必要なければ使わなくて構いません。

```
MioPrototype.exe -sfxaudition                    効果音を1音ずつ聞く（1〜0 / Space）
MioPrototype.exe -holdright -screenspan=7        右へ自動で歩き、波の間隔を 7m にする
MioPrototype.exe -encountertest -holdright       敵を自動で倒して波の進行を確認
MioPrototype.exe -maxwaves=3                     3 波でクリア（終わり方の確認）
MioPrototype.exe -camdist=5.2                    カメラ距離を差し替える
MioPrototype.exe -jointrom -jointlog             関節が人体の可動域を超えたら警告（Joint-ROM.md）
```

引数を付けて起動した場合も、すぐ始まります。タイトルを出したいときだけ `-title` を付けます。
