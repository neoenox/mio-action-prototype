# 可愛い判定ビューア

VRM を放り込むと、神楽澪の「可愛い」を判定できるツール。
ブラウザだけで動くので Unity は不要。

---

## 起動

```powershell
python -m http.server 8765 --directory C:\gemini-desktop\ryona-action\viewer
```

→ ブラウザで http://localhost:8765/ を開く

`index.html` を直接ダブルクリックでも動く場合がありますが、
CDN から three.js を読む都合上、ローカルサーバー経由を推奨。

---

## 使い方

1. VRoid Studio から `.vrm` で書き出す
2. 画面に**ドラッグ&ドロップ**
3. 下の手順で判定する

### 判定手順(この順番で見る)

| 順 | 操作 | 見るもの |
|---|---|---|
| 1 | カメラ「顔」 | 目が魅力的か。瞳のハイライト、まつ毛 |
| 2 | カメラ「バスト」 | 顔と肩のバランス。首が長すぎ/短すぎないか |
| 3 | カメラ「全身」+ Aポーズ | シルエットが「強そう」か |
| 4 | 照明「廃工場」+ 背景 #4A4A4E | 実際のゲーム画面で埋もれないか |
| 5 | 自動回転 ON | 360度見て破綻がないか |
| 6 | 表情スライダー | `angry` `sad` などで痛み表現の素地を確認 |
| 7 | スクショ保存 | 記録に残す |

**1〜5 のどれかが落ちたら VRoid の顔に戻る。戦闘実装には進まない。**

---

## 機能

- **カメラ3種**: 全身 / バスト / 顔(自動フレーミング)
- **照明4種**: 標準 / 廃工場 / リム強 / フラット
- **背景3種**: `#4A4A4E`(廃工場)/ 黒 / 白
- **ポーズ**: Tポーズ / Aポーズ(シルエット判定用)
- **表情**: VRM の全 BlendShape をスライダーで操作
- **自動回転**: 360度チェック
- **スクショ保存**: PNG で書き出し

---

## 実装メモ

- three.js 0.160 + @pixiv/three-vrm 3.0(CDN 読み込み)
- VRM 0.x / 1.0 の両対応(`VRMUtils.rotateVRM0` で向きを補正)
- カメラのフレーミングはバウンディングボックスから自動計算
  → 身長が違うモデルでも同じ構図になる
- Aポーズは Humanoid の正規化ボーン(`UpperArm`)を回転させて作っている
  → アニメーションを入れても干渉しない

---

## 既知の制約

- 初回読み込み時にネット接続が必要(three.js を CDN から取得)
- ポーズは T/A の2種のみ。被弾リアクションの確認は Unity 側で行う
- 破損レベル(汚れ・裂け)の確認はテクスチャ差し替えが必要なので未対応

---

## 検証記録

VRM サンプル(three-vrm 公式のテストモデル)で以下を確認済み。

- VRM 読み込み → 18 個の BlendShape を認識
- カメラ3種のフレーミング正常
- Aポーズ切替正常
- 照明・背景切替正常
- コンソールエラーなし
